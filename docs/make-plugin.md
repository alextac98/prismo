# How to Make Your Own Plugin

Prismo is designed to be extended with custom plugins that can emit telemetry from any source. This guide walks through the steps to create a new plugin, from defining the manifest to emitting data.

While the plugin system is complete, the documentation is not! Come back soon for more detailed guides, examples, and SDK references. In the meantime, the best way to get started is to check out the existing example plugins in the repo and use them as a template for your own.
